# session-priority 插件开发约束

本插件用一个新会话 Hook 和两个可主动调用的技能维护会话名：

- Hook 只负责在有人值守且工具齐全的新会话中提醒智能体询问初始优先级。
- `set-session-priority` 负责随时设置或修改 `[P0]`、`[P1]`、`[P2]`。
- `session-parking` 负责添加或移除 `[PARKED]`，不改变真实归档状态。

## 共同约束

1. 标题前缀顺序固定为 `[P0][PARKED] 标题`。
2. 所有改名操作必须幂等，禁止重复叠加同类标记。
3. 自动化、定时任务、后台执行或其他无人值守场景不得提问。
4. 三份宿主清单的共有元数据保持一致；Codex Hook 必须在其清单中显式声明。
