# Set Session Priority

- 从调用参数和用户请求中识别 `p0`、`p1`、`p2`，不区分大小写。只有一个明确值时直接改名，不提问。
- 未指定或出现冲突值时才使用提问工具确认；自动化、定时任务、后台执行等无人值守场景不提问、不改名。
- 仅在具备读取和修改会话名工具时执行。
- 添加优先级，或替换已有 `[P0]`、`[P1]`、`[P2]`；只保留一个。
- 保留 `[PARKED]`，标题顺序固定为 `[P0][PARKED] 标题`。
- 名称无需变化时不调用工具，保证幂等。
